hooks

every hook has a face.

Claude Code fires a hook at each step. the bridge turns it into one short line over USB, and the firmware picks an animation for it. hover a key, or tap it.

no hook

a few hooks pick from a small pool, so the same event can look different next time. the usb lines are the real protocol, see PROTOCOL.md.

firmware and bridge

build one.

1

flash the board

get the .bin from the releases page. open espressif's web flasher in Chrome, connect, pick the file at address 0x0, press program.

2

set up the laptop

the bridge, the Claude Code hooks and the usage line, in one go. it backs up every file it touches. restart Claude Code and say hi.

curl -fsSL https://tinyclawd.deepakpopli.in/install.sh | bash

or set it up by hand.
