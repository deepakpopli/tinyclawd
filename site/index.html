> tiny clawd

a tiny Clawd that lives on your desk and reacts to Claude Code.

it thinks when claude thinks, types when claude edits, flashes when claude needs you and scores a goal when the task is done. when nothing is going on it just plays football.

3D printed · ESP32-C3 · 1.3" OLED face · about $10 of parts

build one github

01 it reacts to everything

claude code hooks talk to it over usb. every tool gets its own look.

  • failing tests get a yellow card, then a red one
  • running low on usage: tired, stoppage time, limit hit
  • several sessions share one Clawd. whoever needs you wins, little dots show who's busy

02 it has a life

no laptop, no problem. it looks around, has a coffee, juggles, naps and dreams. at night it falls asleep faster. put on a song and it vibes along.

87 animations, all drawn on the real 128x64 screen. these gifs come straight from the firmware.

03 games

7 games, one button: the touch pad on its head. tap, double tap, hold. they're easy on purpose, it's a desk toy. best scores survive unplugging.

04 build your own

about $10 of parts and an evening. it's not for sale, you make it.

parts

ESP32-C3 Super Mini~$3
1.3" SH1106 OLED, 128x64, I2C~$4
TTP223 touch pad~$0.5
USB-C data cable~$2
~40 g of PLA, red + black~$1
total~$10

print files (body, back plate, stand) are in hardware/print. each folder has a README with what to print.

1. flash the board

grab the .bin from the releases page, open espressif's web flasher in chrome, connect, pick the file at address 0x0 and press program.

2. set up the laptop

this installs the bridge, the claude code hooks and the usage line:

curl -fsSL https://tinyclawd.deepakpopli.in/install.sh | bash

or by hand. it backs up every file it touches. restart claude code after and say hi.
