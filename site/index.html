how it works

from a hook to a pixel.

nothing leaves your laptop. Clawd gets the event, the tool name, the project folder name and your usage. never your prompts or code.

  1. 01

    Claude Code

    every prompt, tool call, permission prompt and finish runs a hook. the status line adds your usage.

  2. 02

    the bridge

    a small Python service on the laptop turns each one into a short line of text, like ev tool Bash, and sends it over USB.

  3. 03

    Clawd

    the ESP32 picks what to play and draws it at 40 fps. when nothing is talking to it, it just lives on its own.

build

build one.

you need a 3D printer, the parts above, a USB-C cable that carries data and a Linux laptop with Claude Code.

  1. 01

    print the body

    body, back plate and stand are in hardware/print. no supports. the inner frame is the Mochi housing by Dave0616, so it fits as is.

  2. 02

    flash the board

    get the .bin from the releases page. open espressif's web flasher in Chrome, pick the file at address 0x0, press program. or let the command below do it.

  3. 03

    set up the laptop

    one command installs the bridge and adds the Claude Code hooks, the /clawd command and the usage line. restart Claude Code and say hi.

one command

curl -fsSL https://tinyclawd.deepakpopli.in/install.sh | bash

asks before it flashes anything. backs up your Claude Code settings and status line script before it changes them. the usage line goes into your status line script, if you have one.

or let Claude Code set it up

Set up Tiny Clawd for me from github.com/deepakpopli/tinyclawd: clone it, install what the bridge needs, ask me before flashing my ESP32-C3, then add the Claude Code hooks and the usage status line. Ask before changing any file.

paste it into Claude Code. or set it up by hand.
