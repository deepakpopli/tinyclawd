hook UserPromptSubmit

you hit enter

it starts thinking with the same words the CLI uses: pondering, noodling, percolating, clauding.

  • you typeit watches the keys go down. speed only, never which keys. you can switch it off.
  • you press enterthinking words, same as the CLI

hook PreToolUse

every tool gets its own look

Bash commands are sorted by what they do, so a build looks different from a test run.

  • Readreading, a page flip
  • Grepsearching, a radar sweep
  • Edittyping code
  • WebSearcha globe, a satellite
  • makea building crane
  • npm testbubbling test tubes
  • git commita git graph, then a party
  • pip installpackages coming down

hook SubagentStart

a squad for subagents

when Claude Code starts subagents, mini Clawds march in, one for each, and pass a ball around.

another one joins as a substitute. when the last subagent stops, the squad walks back out.

hook PermissionRequest

it calls you back

a permission prompt or a question? the whole screen flashes the project name until you answer, so a session never sits there waiting while you are in another window.

several sessions share one Clawd. whoever needs you wins, then whoever is working. dots in the corner show how many are busy.

hook Stop

it celebrates

how long the turn took picks the party.

  • under 20 sa small win
  • 20 s to 2 mingoal, header, party
  • over 2 mingoal, trophy, bicycle kick
  • test failsyellow card
  • fails againred card

from the laptop audio

music on

play something on the laptop. the song name scrolls by, and the equalizer bars move to the real laptop audio, not a fake loop.

when nothing is running

idle? it has a coffee

or it juggles, plays football, stares at the stars and naps. at night it falls asleep faster.

what it does is picked at random with cooldowns, so it rarely does the same thing twice in a row.

press a hook

Claude Code fires a hook at each step. the bridge sends one short line over USB, and the firmware picks an animation for it. these are the real frames.
